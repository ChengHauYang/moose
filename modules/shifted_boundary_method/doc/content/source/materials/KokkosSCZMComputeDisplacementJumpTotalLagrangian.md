# KokkosSCZMComputeDisplacementJumpTotalLagrangian

!syntax description /Materials/KokkosSCZMComputeDisplacementJumpTotalLagrangian

Computes the shifted cohesive displacement jump in local and global coordinates, the surrogate-interface
deformation gradient $F$, polar decomposition $R$, and reference rotation $R_{ref}$ for total-Lagrangian
kinematics with Kokkos.
