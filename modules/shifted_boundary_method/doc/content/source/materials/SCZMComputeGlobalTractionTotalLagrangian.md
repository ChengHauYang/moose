# SCZMComputeGlobalTractionTotalLagrangian

!syntax description /Materials/SCZMComputeGlobalTractionTotalLagrangian

This material rotates a local cohesive traction to the global frame and applies the Nanson area
transformation for total-Lagrangian SCZM. The Nanson transformation uses the true-interface
reference normal rather than the surrogate-face normal.
