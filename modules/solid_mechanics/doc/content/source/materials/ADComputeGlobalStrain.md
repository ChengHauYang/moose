# ComputeGlobalStrain / ADComputeGlobalStrain

!syntax description /Materials/ADComputeGlobalStrain

## Description

`ADComputeGlobalStrain` extracts AD values from the global-strain scalar variables and stores them as an AD strain tensor. It preserves derivatives of the scalar global strain. The resulting global strain is added to the total strain.
