# GlobalStrainUserObject / ADGlobalStrainUserObject

!syntax description /UserObjects/ADGlobalStrainUserObject

## Description

`ADGlobalStrainUserObject` computes the AD residual and periodic directions for global strain. The AD residual preserves stress derivatives, including derivatives with respect to displacements and the global-strain scalars.
